# n8n_repository

n8n is a workflow automation platform that connects apps and services to automate tasks with little or no code.

This repository contains n8n workflows, configuration, and related resources for workflow automation.

## Fibonacci

`fibonacci.py` provides a `fibonacci(n)` function that returns the nth Fibonacci number using zero-based indexing, with `F(0) = 0` and `F(1) = 1`.

The function requires a non-negative integer and raises an error for invalid input.
